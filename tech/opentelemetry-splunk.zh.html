OpenTelemetry & Splunk

以 OpenTelemetry 作为 LLM 与智能体遥测标准，以 Splunk 作为 SIEM 落地端。

01 这是什么？

OpenTelemetry 是遥测、链路、指标与日志的开放标准，OpenTelemetry GenAI 语义约定现已覆盖 LLM 与智能体链路。Splunk 是众多受监管行业既已采用、用于接入与处理此类遥测的成熟 SIEM 与可观测性平台。

02 为什么要采用？

  • 供应商中立的遥测标准
  • 面向 LLM 链路的 OpenTelemetry GenAI 语义约定
  • Splunk 提供数据接入、检索、告警与合规
  • 复用既有的 SIEM 投资与运营模式
  • 与 Langfuse、Phoenix 与 Datadog 协同良好

03 我如何提供帮助

我按 OpenTelemetry GenAI 约定为贵司智能体栈做埋点，设计收集器拓扑，把链路与日志路由至 Splunk 与 LLM 可观测性平台，并定义检测与审计 playbook。

04 预期交付物

  • OpenTelemetry 埋点方案
  • 收集器拓扑与路由设计
  • Splunk 接入与检测 playbook
  • SIEM 与审计集成
  • 运营模式与值班 playbook
